# Boykisser Pet :3

**Маленький бойкиссер, который живёт прямо на рабочем столе Windows.**

Анимации, реакции на системные события и танцы под музыку — теперь в версии **2.1.0**.

</div>

---

## ✨ Возможности

### 🐾 Настольный питомец
- Анимированный персонаж, который двигается, разговаривает и иногда устраивает случайные события.
- Можно переименовывать питомца, гладить, кормить и укладывать спать или будить.
- Перетаскивание по рабочему столу левой кнопкой мыши.
- Ручные и случайные танцы.
- Настройки поведения доступны в окне настроек приложения.

### 🖱️ Игры с курсором
- Время от времени питомец замечает указатель мыши, бежит за ним по полу, приседает и **прыгает на курсор**.
- Если прыжок попал, настоящий курсор **отлетает в сторону** (отключается в настройках). Если ты увёл курсор вовремя, питомец промахнётся.
- Ничего не сбивается, пока зажата кнопка мыши, а при полноэкранном приложении поведение ставится на паузу.
- Запустить вручную: правый клик по питомцу → **«Побегать за курсором»**.

### 🖼️ Редкое событие: картинка с края экрана
- Иногда питомец убегает за левый или правый край экрана и через пару секунд **затаскивает оттуда случайную картинку** (в духе Desktop Goose), оставляя её на рабочем столе.
- Клик по картинке закрывает её; сама она исчезает через 3 минуты. Одновременно на экране остаётся не больше пяти.
- Запустить вручную: правый клик по питомцу → **«Принести картинку»**.

### 🪟 Интеграция с Windows
- **Запуск вместе с Windows** — можно включить автоматический запуск.
- **Предупреждение о низком заряде** — питомец напомнит, когда батарея разряжается.
- **Напоминание поздно ночью** — небольшая забота о твоём режиме сна.
- **Реакция на уведомления** — питомец отслеживает доступные Windows UI-события и текст уведомлений поддерживаемых приложений. При обнаружении подходящего уведомления он может испугаться и укатиться.
- **Реакция на громкие звуки** — приложение периодически проверяет уровень звука отдельных процессов. Громкий звук может напугать спящего питомца; задержки между реакциями помогают избежать постоянных срабатываний.

### 🎵 Танцы под музыку — новое в 2.0.0
- Получение названия трека, исполнителя и состояния воспроизведения через **Windows SMTC (System Media Transport Controls)**.
- Поиск совпадения с помощью **LRCLIB**.
- Если подходящий трек найден, питомец может начать танцевать.
- Реакция учитывает состояние воспроизведения: танец должен прекращаться при паузе, остановке или смене трека.

> Для поиска информации о треке нужен доступ к интернету. Работа функции зависит от того, передаёт ли проигрыватель метаданные в Windows, а также от доступности LRCLIB.

## 📥 Установка и запуск

1. Открой раздел **Releases** этого репозитория.
2. Скачай архив или готовую сборку, приложенную к нужному релизу.
3. Распакуй архив, если он упакован.
4. Запусти приложение.

---

## 🖼️ Свои картинки для события

Перед сборкой положи файлы `mem1.webp` … `mem7.webp` в папку `Assets` (рядом с `BoykisserPet.csproj`). Они встраиваются в exe так же, как GIF. Лишние номера можно пропустить: отсутствующие файлы просто не участвуют, а если нет ни одного, питомец не уходит за картинкой.

## ⚙️ Настройки и журналы

Доступные реакции и поведение можно настраивать в окне настроек приложения.

Диагностический журнал системных реакций находится здесь:

```text
%APPDATA%\BoykisserPet\system-reactions.log
```

Если питомец ведёт себя странно или какая-то реакция не срабатывает, этот файл может помочь при поиске причины.

## ⚠️ Известные ограничения

Некоторые функции зависят от приложений и возможностей Windows, поэтому их поведение может отличаться на разных системах.

- **Уведомления:** Windows UI Automation не всегда предоставляет текст уведомления. В таком случае приложение может его пропустить.
- **Громкие звуки:** проверка выполняется периодически, поэтому очень короткие звуки могут не попасть в измерение. Уровень оценивается для отдельных аудиопроцессов, а не по положению общего ползунка громкости Windows.
- **Музыка:** танцы зависят от доступности Windows media session, корректных метаданных трека и ответа LRCLIB. Если проигрыватель не передаёт информацию о треке или сервис недоступен, совпадение может не найтись.
