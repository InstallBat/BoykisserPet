# BoykisserPet
Маленький Boykisser, который живёт прямо на рабочем столе Windows 💜
Boykisser Pet — это интерактивный десктопный питомец с анимациями, звуковыми эффектами и управлением через мышь. Он может танцевать, реагировать на взаимодействия и оставаться поверх остальных окон, пока ты занимаешься своими делами.

✨ Возможности

🐾 Анимированный питомец — персонаж отображается прямо на рабочем столе.

🖱️ Взаимодействие с мышью — возможность перетаскивать питомца и взаимодействовать с ним.

💜 Поглаживание — отдельное действие для взаимодействия с персонажем.

💃 Танцы — возможность запускать танцевальную анимацию вручную или дождаться её автоматического запуска.

🔊 Звуковые эффекты — мяуканье и другие звуки при взаимодействии.

🪟 Поверх всех окон — питомец может оставаться на переднем плане.

🐈 Милый компаньон — небольшой способ добавить немного Boykisser на свой рабочий стол.

🛠️ Установка и запуск

Запуск готовой версии

Если в разделе Releases доступна готовая сборка, скачай её и запусти исполняемый файл.

Сборка из исходного кода

Для сборки понадобится Windows и установленный .NET 8 SDK.

Склонируй репозиторий или скачай его через Code → Download ZIP.

Распакуй архив, если скачивал ZIP.

Открой терминал в папке проекта.

Выполни команду:

dotnet publish -c Release

После успешной сборки ищи исполняемый файл в каталоге публикации внутри bin\Release\.

Если сборка не запускается, проверь, что установлен .NET SDK нужной версии и все необходимые файлы ресурсов присутствуют в проекте.
